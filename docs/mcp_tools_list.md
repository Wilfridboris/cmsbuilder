# 100 Model Context Protocol (MCP) Tools and Servers

The Model Context Protocol (MCP) standardizes how AI agents connect to data sources, local development environments, and external enterprise software APIs. 

Below is an extensive collection of 100 popular and practical MCP tools and servers grouped by function:

---

## 💻 1. Core Developer Tools & System Operations
1. **Official Filesystem MCP**: Secure, configurable read/write access to specified directories on a local file system.
2. **Official GitHub MCP**: Conversationally manage repositories, review pull requests, create issues, and search code blocks.
3. **Official GitLab MCP**: Sync agent workflows with GitLab repositories, commit histories, CI/CD pipelines, and merge requests.
4. **Sentry MCP**: Trace application bugs, pull error stack traces, and fetch real-time issue statistics for debugging.
5. **Kubernetes MCP**: Inspect cluster health, view pod logs, describe resources, and troubleshoot nodes.
6. **Docker MCP**: Inspect container networks, manage local image builds, and restart halted system containers.
7. **AWS MCP**: Monitor cloud infrastructure resource statuses, interact with S3 buckets, and query Lambda metrics.
8. **Cloudflare MCP**: Evaluate CDN workers, purge edge caches, and check DNS records or domain health.
9. **Azure MCP**: Management interface for Microsoft Azure resources, virtual machines, and cloud storage accounts.
10. **Google Cloud Platform (GCP) MCP**: View Compute Engine instances, list BigQuery tables, and audit IAM permissions.
11. **Local Terminal/Shell MCP**: Safely executes terminal commands in a sandboxed shell environment for automation.
12. **SSH MCP**: Connects securely to remote servers to execute scripts and fetch configuration data.
13. **Vercel MCP**: Manage frontend deployment queues, view build logs, and update domain environment variables.
14. **Heroku MCP**: Control application dynos, view metrics, and manage configuration variables.
15. **Netlify MCP**: Check build health, configure serverless redirects, and manage static site projects.
